# Simple E-Commerce Website

A basic front-end e-commerce website layout built using HTML and CSS.

- Responsive grid layout
- Clean UI design
- Ready for JavaScript cart integration

## Tech Stack
- HTML5
- CSS3

## How to Run
1. Clone the repository
2. Open `index.html` in any browser
